## 1. 공통 합의 사항

교재 기법은 행이 서로 독립이고 무작위로 7:3 분할해도 된다는 가정에 서 있습니다. 이 프로젝트의 자료는 단지 거래가 반복되고 시계열·패널·공간 구조를 갖기 때문에 그 가정이 성립하지 않습니다. 그래서 **기법은 교재에서 가져오되, 분할 단위와 평가 기준을 바꾸는 것**을 공통 원칙으로 합니다.

1. **분할**
   - 주결과: 단지·동 단위 그룹 분할(GroupKFold, 공간 블록), 시간순 분할, 워크포워드.
   - 무작위 분할: "같은 기간·같은 단지 안의 보간 성능"으로만 병기합니다.
   - 기존 점검 기준, 분할 방식에 따른 R² 차이:

     | 노트북 | 무작위 분할 | 그룹 분할 |
     |---|---|---|
     | 03 | 0.928 | 0.762 (단지 분할) |
     | 05 | 0.723 | 0.379 (동 분할) |

2. **이상치**
   - 교재 6장처럼 IQR로 행을 삭제하지 않습니다. 고가 거래가 실제 값인데도 체계적으로 사라집니다.
   - 일괄매각, 같은 단지·같은 날 대량 거래, 미완결 월, 취소 거래는 플래그로 표시합니다.
   - 결과는 포함본과 제외본을 나란히 제시합니다.
   - 근거: 기존 점검에서 10건 이상 묶음을 제외하면 전월 대비 −3.45%가 +1.87%로 바뀝니다.

3. **전처리 누수 방지**
   - 정규화(MinMax)는 학습 구간에서만 fit합니다.
   - 오버샘플링을 쓴다면 학습 폴드 안에서만 적용합니다.

4. **해석 표현**
   - 특징 중요도와 계수는 "예측 기여도"나 "연관"으로만 씁니다. 인과로 서술하지 않습니다.
   - 투자 권유로 읽힐 수 있는 표현은 쓰지 않습니다.

5. **재현성**
   - 시드는 `SEED=42` 한 곳에서 관리합니다.
   - 분할 인덱스를 저장합니다.
   - 결과 CSV와 함께 실행 환경 버전을 기록합니다.

### 02 급지와 선행·후행

  - 부트스트랩이나 기준연도 변경으로 군집 안정성(ARI)을 확인합니다.
  - 기존 점검의 실루엣은 k=3에서 0.569, k=4에서 0.560이었습니다. 두 결과를 모두 제시합니다.

- **유지:** 선행·후행은 교재 기법으로 대체할 수 없으므로 아래 방법을 그대로 유지합니다.
  - ADF와 차분
  - AIC/BIC 시차 선택
  - Granger 검정
  - FDR 보정
  - HAC 표준오차
  - VAR 점검
- **주의:**

### 03 아파트 특성(면적·연식·층)
- **교재 기법:** 5장 다중회귀, 3장 결정트리(깊이 3~4), 4장 kNN, 10장 MLP. RF는 기준선으로 둡니다.
- **설계:**
  - 타깃: log(㎡당 가격).
  - 연식·층: 구간 더미나 스플라인으로 비선형을 반영합니다. 연식은 재건축 기대로 U자형일 수 있습니다.
  - 분할: GroupKFold(단지)와 시간순 홀드아웃(예: 2024년까지 학습, 2025년부터 평가)을 함께 보고합니다.
  - 하이퍼파라미터: 학습 구간 안의 검증셋에서만 고릅니다(교재의 3분할).
  - 회귀 표준오차: 단지 클러스터로 계산합니다.
  - 결정트리: 분기점(재건축 연한 30년, 저층 1~2층, 84㎡)이 업계 상식과 맞는지 보는 해석 도구로 씁니다.
- **지표:** MAE·RMSE·R²(억원 환산 MAE 병기), 학습 시간
- **주의:**
  - kNN은 (구, 건축년도, 면적) 조합으로 같은 단지를 사실상 찾아내 누수가 가장 큽니다. 단지 분할 결과로만 평가합니다.
  - "층이 높으면 가격이 오른다" 같은 인과 표현은 쓰지 않습니다.
- **우선순위:** 상

### 07 저평가·시나리오
- **07-1: "다음 분기 상대 상승" 분류로 재구성**
  - **단위:** 동×분기 구성 보정 가격
  - **레이블:** 다음 분기(또는 다음 4분기) 상승률이 서울 중위보다 높거나 상위 30%이면 1. 상대 기준으로 잡아야 시장 국면이 레이블을 지배하지 않습니다.
  - **입력:** t 시점까지 관측 가능한 값만 씁니다.
    - 괴리율
    - 모멘텀(직전 1·4분기 상승률)
    - 거래량
    - 평균 연식
    - 단지 규모
    - 재건축 연한 비중(연식 30년 이상)
    - 급지(기준연도 고정)
    - 정책 더미
  - **괴리율 산출:** 매 시점 t의 횡단면 모형을 t 이전 자료로만 다시 적합합니다.
  - **모델:** 로지스틱(6장), 가우시안 NB(6장), 결정트리(3장, 깊이 제한), MLP(10장, 작은 구조 + early stopping)
  - **기준선:** 다수 클래스 예측, 모멘텀 단일 변수 로지스틱
  - **핵심 질문:** 괴리율을 넣고 뺐을 때 AUC가 얼마나 달라지는가
  - **검증:** 확장 윈도우 워크포워드에 결과 기간만큼 퍼지(purge) 간격을 둡니다. 무작위 k-fold는 쓰지 않습니다.
  - **지표:** AUC, 정밀도·재현율, precision@k(기본 비율과 비교), Brier 점수, 혼동행렬. 국면별(2020~21, 2022~23, 2024~)로 나눠 보고합니다. 정확도(CA)는 주지표로 쓰지 않습니다.
  - **제외 기준:** 분기 거래가 10건 미만인 잡음 큰 동의 제외 기준을 미리 정합니다.
- **07-2: 시나리오**
  - 5장처럼 미래 입력을 외삽하지 않습니다.
  - 가정 격자를 사용합니다: 금리 −1.0~+1.0%p, 통근 −10~0분.
  - 계수는 단일값 대신 사양별 범위나 부트스트랩 구간으로 넣습니다.
  - 결과는 "가정 하의 계산 범위"로 표기합니다.
  - 통근 시나리오는 서울 전체에 일괄 적용하지 않습니다. 특정 동만 바뀌었을 때의 상대 가격 차이로만 제시합니다.
- **07-3: 모델 비교**
  - 03~05 통합 특성으로 선형, 트리, kNN, RF, MLP를 비교합니다.
  - 분할은 시간순 하나로 통일합니다.
- **주의:**
  - 기존 결과는 상대변화 MAE가 모형 5.86%p, 평균 예측 5.84%p이고 순위상관은 약 0.00입니다. "예측력 없음"이 유지될 수 있으며, 이것도 결론으로 받아들입니다.
  - 압구정·여의도가 고평가로 나오는 것은 재건축 요인이 모형에서 빠진 탓일 수 있습니다.
  - **"저평가 동" 명단은 공개하지 않습니다.** 워크포워드 AUC가 기준선을 넘기 전까지는 내부 검증용으로만 씁니다.
- **우선순위:** 상(07-1 재구성), 하(MLP 심층 구조·CNN)

| 7:3 무작위 분할, 10-fold | 주결과에서 제외 | 단지 중복과 시계열 때문에 누수가 생김 |
| IQR 일괄 삭제(6장) | 사용 안 함 | 실제 고가 거래가 사라짐. 플래그로 표시만 함 |
| SMOTE(6장) | 사용 안 함 | 가격 예측은 회귀 문제이고, 07도 상위 30%로 정의하면 균형이 맞음. 필요하면 class_weight를 씀 |
| 나이브베이즈(6장) | 07의 기준선으로만 | 연속 변수 사이 상관이 강함 |
| 연관규칙(9장) | 04 서술용 보조 | 이산화 기준에 결과가 좌우되고 인과가 아님. 06에는 쓰지 않음 |
| MLP(10장) | sklearn으로 작은 구조만 | keras는 미설치. 동 단위 표본이 작아 과적합 위험이 크므로 교재 10장의 과적합 경고를 재현하는 사례로 씀 |
| CNN 임베딩(11장) | **적용하지 않음** | 이미지 자료가 없음. 위성사진·로드뷰를 받으려면 외부 API가 필요한데 금지됨 |
| 5장식 외삽 시나리오 | 가정 격자로 대체 | 추세가 기계적으로 이어지고, 금리는 내생적임 |
| 결정트리 특징 중요도 | permutation importance로 보완 | 고카디널리티 변수가 과대평가됨 |

## 4. 쟁점별 조율 결과

1. **06 상승/하락 분류:** 도메인은 찬성, 통계는 반대했습니다. → 분류는 07로 옮기고 정책은 07의 특징으로만 씁니다.
2. **연관규칙 사용:** 웹은 제외, 도메인·분석·통계는 보조 사용을 주장했습니다. → 04의 동 특성 조합에만 서술용으로 씁니다.
3. **군집 수와 이름:** 실루엣 최고점은 k=3, 업계 관행은 4~5급지입니다. → 두 결과를 모두 제시하고 이름은 중립적으로 붙입니다. 가격을 뺀 유형화를 `src/재검증/02b_` 추가안으로 둡니다.
4. **이상치 처리:** IQR 삭제와 분리 보고 사이에서 → 분리 보고(플래그와 포함·제외본 병기)로 정하고, 규칙을 사전에 고정합니다.
5. **성능 수치와 발표 메시지:** 정직한 분할을 쓰면 수치가 내려갑니다. → 그룹·시간순 결과를 주결과로 하고, 무작위 결과는 병기만 합니다. 이렇게 하는 데 전원이 합의했습니다.
6. **의존성:** 교재 충실도와 환경 안정성 사이에서 → keras 대신 sklearn MLP를 씁니다. 패키지 설치는 사용자 승인 후에만 합니다.
7. **Orange3:** 사용하지 않습니다. 교재의 기법만 가져와 파이썬(scikit-learn·statsmodels) 노트북으로 구현하고, 모든 수치는 노트북 기준으로 냅니다.

## 7. 결과 산출물·웹 화면 요구사항 (web-builder)

- **화면 구조:** 각 상세 화면에 교재 6단계 탭을 둡니다.
  1. 문제정의: 관측·연관·예측·시나리오 중 어떤 유형인지 배지로 표시
  2. 데이터: 표본 수, 기간, 제외 기준, 한계
  3. EDA·전처리
  4. 모델: 분할 방식 명시
  5. 평가: 과적합 경고 포함
  6. 활용·한계: 해도 되는 해석과 하면 안 되는 해석을 나란히
- **산출물 형식:**
  - 컬럼명을 고정한 tidy CSV로 저장합니다.
  - 영역마다 `summary.csv`와 차트별 CSV를 두고, `sample_n, period, split_type` 메타 정보를 붙입니다.
  - 03~05와 07은 무작위 분할과 시간순·그룹 분할 성능을 같은 표에 나란히 저장합니다.
  - 교차검증 결과는 평균과 표준편차를 함께 저장합니다.
  - PNG는 트리 시각화처럼 JS로 그리기 어려운 것만 씁니다. 폭 1200px 이하, 약 200KB 이하로 합니다.
  - 시나리오 슬라이더는 미리 계산해 둔 격자 CSV를 읽습니다. JS에서 다시 계산하지 않습니다.
  - 지도는 타일 없이 좌표 점 산점도로 그려 오프라인에서도 동작하게 합니다.

## 8. 발표용 질문 재구성 (도메인 제안)

1. **"헤드라인 집값은 왜 시장과 반대로 움직였나"**: 중위가격과 구성 보정 지수의 차이를 거래 구성 효과로 설명합니다.
2. **"가격을 빼고 묶어도 급지가 다시 나타나는가"**: 가격 없이 동을 유형화하고, 연관규칙으로 학원가·노후 대단지·역세권이 어떤 조합으로 함께 나타나는지 보입니다.
3. **"설명은 되는데 예측은 왜 안 되나"**: 같은 시점 동 간 비교의 R²(0.68~0.93)와 시간순 예측 실패를 대비합니다. "모형 가격보다 낮다 ≠ 오를 것이다"를 정면으로 보여줍니다.

**결론 문장 후보:** "단지 단위로 분리해 평가했을 때 면적·연식·층의 예측 기여도는 ○○였으며, 저평가 지표는 모멘텀 기준선 대비 추가 예측력을 보이지 않았다(국면별 AUC ○○)."
